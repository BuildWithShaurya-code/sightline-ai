# Demo checklist

Use this as a preparation list, not a claim that each item is complete.

- [ ] Confirm HYPNEXIS problem statement, deadlines and reuse rules in the registration portal.
- [ ] Add actual team names and a truthful existing/event-work record.
- [ ] Prepare consented clips: positive person/mask, positive knife and a negative control. Label missing evaluation honestly.
- [ ] Verify checkpoint hash, installed dependencies and application readiness on the demo laptop.
- [ ] Rehearse sign-in, private contact save/edit/reload, upload, analysis, evidence, confirmation and history.
- [ ] Use dummy contact/address details in screenshots and recordings; keep private sessions out of exported files.
- [ ] Keep dispatch simulation labelled. Do not call or message a real recipient unexpectedly.
- [ ] Test browser siren permission before presenting; use headphones/appropriate volume where needed.
- [ ] Check a second account cannot see the first account’s data on the final setup.
- [ ] Test restart and offline snapshot/restore with disposable data; keep a private real-data backup separately.
- [ ] Measure complete processing time and memory rather than quoting an unverified FPS claim.
- [ ] Record a redacted fallback demo and identify it as a recording if used.
- [ ] Check the final README, repository/video links and any hosted URL while signed out.
- [ ] Submit the PPT/project through the actual portal and retain its confirmation yourself.
