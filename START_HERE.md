# Start here

Open the live app at https://sightline-ai-eight.vercel.app or read [README.md](README.md) for the current implementation and measured limits.

- [Local setup](docs/SETUP.md): Node 24, Python 3.12, private checkpoint and your own Supabase account.
- [Full Vercel cloud setup](docs/CLOUD_DEPLOYMENT.md): API container, separate daemon, PostgreSQL, private object storage and fail-closed readiness.
- [Verification](docs/VERIFICATION.md): distinguish local tests, actual cloud checks and unmeasured accuracy.
- [Demo script](docs/DEMO_SCRIPT.md) and [submission record](docs/HYPNEXIS_SUBMISSION.md): preserve existing-work disclosure and document event contributions.

There is no default login or PIN. Never commit environment files, credentials, private footage, contacts, databases or model weights. The owner has authorized the tested hackathon release to Vercel and the public sightline-ai GitHub repository. See the release record for observed deployment and publication status.
